# Sales Analysis Dashboard – Power BI

## Overview
This project is an interactive Power BI dashboard created to analyze sales performance, profit, and customer behavior across states, categories, and time.

## KPIs
- Total Sales
- Total Quantity Sold
- Total Profit
- Average Order Value (AOV)

## Key Insights
- Identified top-performing states by profit
- Analyzed monthly profit trends including loss-making months
- Compared sales quantity across product categories
- Evaluated customer payment preferences

## Tools Used
- Power BI
- DAX
- Data Modeling
